# Testing Skill
## Process
1. Đọc requirements và user stories để xây dựng test plan.
2. Xây dựng test cases cho tính năng phân công, thiết lập hạn xử lý, và các chức năng AI (tóm tắt, phân loại).
3. Tạo unit tests và integration tests.
4. Chạy test, phân tích test failures và xuất báo cáo vào docs/test-report.md.
