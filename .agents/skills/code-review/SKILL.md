# Code Review Skill
## Process
1. Kiểm tra tính tuân thủ kiến trúc và yêu cầu nghiệp vụ.
2. Đánh giá tính bảo trì, xử lý lỗi và ngoại lệ (error handling).
3. Phân loại lỗi theo mức độ (CRITICAL, HIGH, MEDIUM, LOW).
4. Xuất báo cáo code review vào docs/code-review.md.
