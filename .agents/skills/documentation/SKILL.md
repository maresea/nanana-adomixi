# Documentation Skill
## Process
1. Đọc toàn bộ project structure và source code.
2. Cập nhật file README.md, tài liệu API và hướng dẫn sử dụng (user-guide.md).
3. Đảm bảo tài liệu không mô tả các chức năng chưa được triển khai.
